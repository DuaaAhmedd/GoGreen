# GoGreen
![image](https://github.com/user-attachments/assets/f4890e0c-392a-47b8-af47-00a7377f06a3)

Built an interactive web application using Python and Streamlit to promote urban greening, featuring data analysis and visualization of survey responses from 'Form.csv'. The app includes a multi-tab interface with home, data overview, visualizations (bar, pie, sunburst charts using Plotly and Matplotlib), and user suggestions, supporting data filtering by location and CSV download functionality.
